# 18 商业可行性调研：品牌方会不会为内容核查付钱

## 0. 这次调研要回答什么

三个**事先定好判定标准**的问题，避免事后找解释：

| 编号 | 问题 | 什么结果算"不成立" |
|---|---|---|
| Q1 | 品牌方是否已经在为"内容/广告合规"花钱 | 找不到任何公开定价或采购记录 → 需求未被商业化 |
| Q2 | 现有供给的价格带说明什么付费意愿 | 主流价格落在消费级（几百元/年）→ 无定价权 |
| Q3 | "主张级事实核查"在品牌侧有没有独立付费位置 | 找不到品牌方为此付费的案例 → 该能力不是独立品类 |

**判定标准（事先写死）**：

- 若"文案合规检测"的公开价格中位数 **< 500 元/年** → 低端已完全商品化，付费意愿弱；
- 若找不到任何品牌方为"事实核查 / AI 查证"付费的**公开案例** → 该能力在品牌侧没有独立市场。

## 2. 需求侧：风险是真实的，而且有明确价签

### 2.1 罚则（核验结果）

《广告法》第 55 条（搜索摘要核验，官方原文页未取到）：

> 广告经营者、广告发布者明知或者应知广告虚假仍设计、制作、代理、发布的，由市场监督管理部门没收广告费用，并处**广告费用三倍以上五倍以下**的罚款；广告费用无法计算或者明显偏低的，处**二十万元以上一百万元以下**的罚款；两年内有三次以上违法行为或者有其他严重情节的，处**广告费用五倍以上十倍以下**的罚款，广告费用无法计算或者明显偏低的，处**一百万元以上二百万元以下**的罚款。

注意两个结构：

1. 罚款基数是**广告费用**，不是销售额。这意味着大投放的品牌罚款极高，小商家罚款很低；
2. "广告费用无法计算"时**直接跳到 20 万–100 万**——这是小微商家最怕的一档，因为他们的广告费通常恰恰算不出来。

**这组数字的用途**：它证明风险是刚性的、可量化的。但它**不能证明付费意愿**——因为品牌方对"文案里有违规词"的第一反应是**改文案**，不是买系统。改文案的成本是零。这是本次调研里最关键的一处推断（E 级），也是第 7 节要验证的第一件事。

## 3. 供给侧：三个价格带，这是付费意愿最硬的证据

公开定价比问卷可靠，因为它代表真实的成交。

### 3.1 免费 / 极低价带：关键词检测

| 产品 | 形态 | 公开价格 |
|---|---|---|
| 句无忧（check51.com） | 违禁词/极限词检测，App + 网页 | 会员月卡 ¥15 / ¥25，年卡 ¥98，终身会员 ¥198 / ¥238 / ¥298，AI 次数包（10000 次）¥198，视频畅享包 1000 分钟 ¥48 |
| 句易网查词（App） | 同类 | ¥28/月 或 ¥88/年 |
| 词爪网、站长工具、UU 在线工具、熊猫关键词工具 | 免费在线检测 | ¥0 |

**这一带的价格锚点已经落在消费级（几十到几百元）**，且被大量免费工具压制。按第 0 节的判定标准：**文案合规检测在低端已经完全商品化，付费意愿弱，且没有定价权。**

### 3.2 企业级内容风控带：真正的 B 端市场

艾瑞咨询《2026 年中国互联网及 AI 大模型内容风控行业发展研究报告》：

| 指标 | 数值 |
|---|---|
| 基于大模型技术的第三方内容风控市场规模 | 2023 年 11.8 亿元 → 2024 年 17.3 亿元 → **2025 年 24.8 亿元** → 2030 年（预测）**93.7 亿元** |
| 年复合增长率 | 超 30% |
| 市场集中度 | 网易智企-易盾约 **43.7%**，位居首位 |
| 商业模式 | **SaaS 部署 + 按量计费** |
| 主要厂商 | 网易易盾、数美科技、360 大模型卫士 |
| 典型客户 | 智谱 AI、Kimi、MiniMax、天工 AI（**大模型应用方，不是品牌方**） |

**这里的买方结构是关键**：客户是内容平台和大模型应用方，不是品牌方。品牌方在这个市场里基本不出现。

### 3.3 云厂商 API 带：能力被当成基础设施卖

阿里云提供"广告敏感词过滤 / 敏感词检测"文本审核 API，明确覆盖"广告法违禁词、极限用语、电商文案、短视频脚本、企业宣传"，**按量计费**。这意味着"检测"这件事正在变成云基础设施的一部分，而不是一个可独立收费的产品。

### 3.4 电商商家工具带：被平台生态吞掉

面向电商商家的合规工具已经很密：旺参谋（1688）、智能店长（京东/拼多多）、店雷达、悟空鉴图（京东）、抖掌柜。共同特征是**做成运营插件的附属功能**，而不是独立收费品类——因为商家的付费对象是"能提升店铺经营的那个工具"，合规只是顺带。

## 5. 直接回答：品牌方有没有实际付费意愿

拆成三类分开答，因为结论完全不同：

| 品类 | 付费意愿 | 依据 |
|---|---|---|
| **关键词级合规检测**（违禁词/极限词） | **弱**。价格锚定在 ¥15–298，被免费工具大量替代 | 应用商店内购价、大量免费竞品 |
| **企业级内容风控** | **有**，但买方是内容平台、大模型应用方、政府部门，**不是品牌方** | 艾瑞市场规模与客户名单、云厂商按量计费 API |
| **主张级事实核查**（本项目的能力） | **未找到任何付费证据** | 检索不到品牌方为"AI 事实核查"付费的公开案例 |

### 5.1 一个反向证据（对"品牌方会付钱"不利）

政府/事业单位侧的采购确实存在且是真金白银：渭南市互联网信息办公室"互联网内容安全服务项目"、西安市公安局雁塔分局"网络信息内容安全服务项目"、湘潭大学"网络安全与内容安全建设采购项目"（均见中国政府采购网公告）。**但买方全部是政府和事业单位，没有一家品牌方。** 这是对"品牌方第一"这一排序的直接反例。

## 6. 不利证据与本次调研的局限（必须写在前面）

1. **易盾 43.7% 这个数字来自易盾托管下载的艾瑞报告**，存在赞助方利益相关，只能当"竞争格局的量级参考"，不能当独立结论；
2. **"内容审核市场 300 亿"是自媒体口径**，与艾瑞的 24.8 亿差一个数量级，说明这个行业的公开数字口径混乱，不能混用；
3. 本次**没有拿到任何一笔政府采购的中标金额**（网站拦截）；
4. 本次**没有做一手访谈**，所有"付费意愿"都是从价格和采购记录倒推的；
5. 广告法条文为搜索摘要核验，**未取到官方原文页**；"医疗/药品/保健食品广告事前审查"这一法定程序未在本次核验完成，第 7 节的第一条切口依赖它。

## 7. 如果一定要往品牌侧做，只有三个可能的切口

按证据强度排序，且每条都写明**依赖的未验证前提**：

1. **强监管品类的"事前审查"**（药品、医疗器械、保健食品、化妆品功效宣称）
   这里的合规支出是法定的、必须发生的，不是效率优化。**前提未验证**：这些企业现在是否已经把审查外包给律所/检测机构并付费，付多少。
2. **卖"检测报告"而不是卖"软件"**（按次收费 + 出具可留存的结论文件）
   理由：品牌方对"报告"的付费习惯已经存在（检测机构模式），对"订阅一个 SaaS"没有。这是产品形态差异，不是能力差异。
3. **放弃品牌侧，回到平台侧内部工具**（即本项目当前定位）
   买方是平台自己，交易形态是内部立项而非采购——这条路不产生"生意"，但产生作品集价值（见第 8 节）。

## 8. 下一步验证（低成本、可执行）

本次调研只证明了"公开证据不足"，**没有证明市场不存在**。要把它变成结论，需要一手证据。按成本从低到高：

### 8.1 三个访谈对象（各 30 分钟，只问过去的行为，不问观点）

优先找：① 消费品品牌（美妆/食品）的电商运营负责人；② 同品牌的市场/法务（负责广告审查的那位）；③ 一家第三方检测机构或广告合规律所的销售。

必须问的六个问题：

1. 最近一次因为文案违规被平台下架或罚款，是什么时候？当时怎么处理的？
2. 一条商品详情页/一条种草文案，从上架前的合规检查到发布，谁在看？花多久？
3. 现在为了"文案不踩线"，一年花了多少钱？花在谁身上（工具/律所/检测机构/人力）？
4. 这笔钱走的是哪个预算科目（市场费用 / 法务费用 / 风险预算）？
5. 上次买合规相关的工具或服务，是谁拍的板？为什么没续费？
6. 如果有一个工具能在发布前把"哪些说法站不住脚"逐条标出来并给出依据，你愿意为此付多少钱、按什么方式付？

### 8.2 事先定好的判定标准

- 若 3 人中 **≥2 人**表示"文案合规的支出低于 5,000 元/年"或"主要靠人盯，没有单独预算" → **品牌侧付费意愿弱的结论成立**；
- 若 3 人中 **≥2 人**能说出一个具体的付费对象和金额 → 需要重新评估，此时询价模型比产品设计更重要；
- 若 3 人全部走"法务/风险预算"而不是"市场预算" → 印证第 7 节的"卖合规、不卖效率"。

### 8.3 一个更便宜的信号测试

不做产品，做一张落地页 + 一个"文案合规体检"的人工服务报价（例如 ¥1,999/次，含逐条结论与依据），投放到品牌运营社群，看有没有人真的付钱。*有人付钱*比*有人说好*有用得多。

## 9. 对本项目的结论

1. **"卖给内容平台"这条线仍不成立**（大厂自建，见上一轮分析）；
2. **"卖给品牌方"这条线在公开证据上更弱**：低端价格已锚定在消费级，B 端市场的买方是平台和政府而非品牌；
3. **"主张级事实核查"目前不是一个可独立定价的品类**——它在平台内部是能力，在云厂商那里是 API，在工具厂商那里是免费功能；
4. 因此本项目的价值仍应落在原定位上：**内容条级分诊 + 可评测迭代 + 平台化**。第 7 节的三条切口是"如果一定要试"的选项，不是结论。
