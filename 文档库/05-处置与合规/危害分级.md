# 危害分级

危害分级回答「动多重」：同一条被证伪的主张，涉及电池安全与涉及主观体验，处置轻重不同。

## 一、三级与词表

判档顺序为 **H3 → H2 → H1**，最后兜底 H2。

| 等级 | 含义 | 词表（摘要） |
|---|---|---|
| H3 高 | 判错可能伤到人身或金钱 | 安全、过热、爆炸、起火、漏电、有毒、致癌、过敏、副作用、儿童、婴儿、孕妇、哺乳、药品、处方、治疗、疗效、降压、降糖、医疗器械、食品、添加剂、成分、认证、资质、批准文号、额定能量、登机、带上机、飞机、航空、承重 |
| H2 中 | 影响消费决策，通常不直接伤到人身 | 续航、容量、功率、参数、性能、材质、价格、原价、折扣、保修、售后、适用、型号、充电、防水 |
| H1 低 | 主观体验类，属于表达问题而非事实问题 | 好用、推荐、喜欢、感觉、体验、值得、舒服 |

除词表外，另有一条主张类型映射：`health_safety` 与 `certification` 直接判 H3。

**依据状态：待补。** 上述词表按「如果这条说法是假的、会伤到什么」逐条选定，尚未逐条挂到出处上。可用的出处有三类：平台规则文本（语料中的社区规范节选）、法规条文（人身安全、健康、认证资质相关表述）、历史处置判例。落实时每条标注「已核原文」或「仅二手转述」。

## 二、判定顺序

顺序为 H3 → H2 → H1。**H2 必须判在 H1 之前**：同一句话里既有消费参数又有主观词时，判成体验类会让动作被降轻——H1 落到只通知创作者，H2 该走降级分发。

| 主张 | 顺序正确时的档位 | 顺序颠倒时的后果 |
|---|---|---|
| 容量 20000mAh，推荐 | H2 | 判成 H1，只通知创作者，不做降级分发 |
| 续航 21 天，用着挺好用 | H2 | 同上 |
| 用着挺好用 | H1 | 无差异 |

## 三、默认值

词表全部未命中时默认 H2。理由：本场景下的主张大多落在「影响消费决策」这一档。

默认值的已知代价：类别词表的覆盖范围决定了哪些主张走默认。当前词表覆盖数码与家电规格较好，食品、饮用水、化妆品、婴童用品、家装材料这些领域尚未收入，相关主张会落到默认档，档位系统性偏低。扩展类别词表的做法是把这些领域直接判 H3；在扩展完成前，走默认档的主张在报告中标注危害档位为假设值。

## 四、与档位的关系

危害性质只在「被证伪且证据足够」时才决定动作轻重：

- 主张判定为支持时走放行，危害不参与；
- 主张被证伪且涉及 H3 时，证据强则打标、证据只有单一来源则转人工；
- 主张被证伪且为 H2 时，证据强则降级分发并通知创作者；
- 主张被证伪但属 H1 时，通知创作者整改即可。
