# 处置档位

回答一个问题：**判断出「这条说法与事实不符」之后，平台该做什么。**

`JUDGED` 只表示有结论，不表示可以放行：一条被判 CONTRADICTED 的主张，可能只是无伤大雅的体验夸大，也可能涉及电池安全，结论一样而处置完全不同。因此在结论与动作之间必须再过一次映射。

## 一、三个维度

| 维度 | 回答 | 取值 | 依据 |
|---|---|---|---|
| 证据强度 E | 能不能动 | E3 强／E2 中／E1 弱／E0 无 | 举证责任：做了对外动作就要拿得出证据 |
| 违规构成 V | 能怎么动 | V2 违规／V1 疑似／V0 无 | 平台规则文本 |
| 危害性质 H | 动多重 | H3 高／H2 中／H1 低 | 处置成本与可逆性 |

### 证据强度

| 取值 | 条件 |
|---|---|
| E3 | 证据充分，且 ≥2 个互相独立的可用来源一致 |
| E2 | 证据充分，但只有 1 个可用来源，无交叉验证 |
| E1 | 不充分：只有低等级来源、来源冲突、来源过期、检索用尽 |
| E0 | 工具失败，本次核查不成立 |

**E1 及以下是一道硬门槛：禁止一切对外动作。** 平台一旦动手，创作者可以申诉、监管会要证据，举不出证据的处置在两边都输。

### 违规构成

前提是一条硬规则：**必须「被证伪」才可能构成违规。**

- SUPPORTED 与 INSUFFICIENT 一律 V0——真实的主张不构成虚假宣传，查不出结论的主张也不能被指控，否则就是拿不确定当罪名；
- CONTRADICTED 且内容带营销特征（推广、合作、素人、测评等）→ V2；
- CONTRADICTED 但无营销特征 → V1；PARTIAL → V1。

### 危害性质

取值 H3／H2／H1，判定规则见「危害分级」。

## 二、规则表

顺序即优先级，**E → V → H 不能调换**：先看危害就会在没证据的时候动手。

| 规则 | 条件 | 档位 |
|---|---|---|
| R1 | E0 | 转人工（系统不可用） |
| R2 | E1 且 H3 | 转人工，优先级最高 |
| R3 | E1 | 转人工（禁止对外动作） |
| R4 | 结论为支持 | 放行 |
| R12 | 结论为证据不足但 E2／E3 | 转人工（证据够却给不出结论＝能力缺口） |
| R5 | V2 | 转违规处置 |
| R6 | V1 且 H3 且 E3 | 打标提示读者 |
| R7 | V1 且 H3 且 E2 | 转人工（单一来源不足以支撑公开动作） |
| R8 | V1 且 H2 且 E3 | 降级分发 + 通知创作者 |
| R9 | V1 且 H2 且 E2 | 转人工 |
| R10 | V1 且 H1 | 通知创作者整改 |
| R11 | 其余 | 转人工（兜底，保守） |
| R13 | 承载结论的来源全是厂商自述，且规则给出的是对外动作 | 转人工（依据不够独立），见下节 |

## 三、来源类型门槛（R13）

处置的依据要经得起申诉与监管：平台一旦做对外动作，就要拿得出可以摆到台面上的独立依据，而厂商自述只能证明「厂商是这么说的」，不能证明「事实如此」。因此：**承载结论的来源全部是厂商自述时，降级分发／打标／转违规三档一律不触发，改写为转人工。**

两处边界：

- **通知创作者整改（R10）不受限制**：它面向创作者本人，不改变内容的分发与公开展示；
- **结论本身照常给出**，照样写进报告（「与厂商标称一致／不一致」），被拦下的只是动作。平台不替厂商背书，也不因为厂商自述而加重处置。

判定读的是承载结论的那几条来源，不是检索回来的整堆材料——抽屉里放着别人的检测报告而结论只引厂商页面，仍然算「仅凭厂商自述」。

## 四、档位

| 档位 | 说明 | 需要人 | 风险 |
|---|---|---|---|
| 放行 | 不改动，仅入库为判例 | 否 | 0 |
| 降级分发 | 不进推荐池／搜索降权，用户无感 | 否 | 2 |
| 打标提示读者 | 在内容上标注该说法未经验证 | 否 | 3 |
| 通知创作者整改 | 给作者发提示，修改后可恢复 | 否 | 4 |
| 转违规处置 | 下架／账号级，须走违规流程并支持申诉 | 是 | 5 |
| 转人工 | 证据不足，不做任何对外动作 | 是 | 1 |

入库为判例不占按钮位——它每次都自动发生。

## 五、两条设计约束

1. **这是门槛制加梯度，不是加权打分。** 若做成评分制（证据 40% + 危害 40% + 违规 20%），「证据不足但危害极大」会被平均成一个中等分然后放行；
2. **规则不匹配时保守转人工。** 兜底分支永远倒向「交给人」，不倒向「动手」。
