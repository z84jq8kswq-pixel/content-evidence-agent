# 来源分级

回答一个问题：**一条材料够不够格支撑一个结论。**

## 一、来源身份与证据等级

来源身份由材料的提供方决定；证据等级是标注时的粗分类，用于任务集与历史数据。

| 等级 | 定义 | 例子 |
|---|---|---|
| E1 | 一手可核验来源 | 官方规格页、说明书、认证机构登记信息、公开政策文本 |
| E2 | 权威第三方 | 检测机构报告、行业标准、专业文献、主流媒体调查 |
| E3 | 用户实测或匿名来源 | 开箱实测、测评博主、论坛反馈 |
| E4 | 营销与不可溯源来源 | 品牌自述、直播口播、无出处的「数据显示」 |

来源类型到来源身份的对应：

| 来源类型 | 来源身份 |
|---|---|
| 监管公开库 | 监管机构 |
| 独立检测 | 独立第三方 |
| 行业组织名录 | 独立第三方 |
| 品牌官方声明 | 厂商自述 |
| 平台规则 | 平台机构 |
| 站内用户内容 | 用户自述 |
| 站内营销内容 | 用户自述 |

## 二、门槛

分级的主判据是**门槛**：只问「这条来源能不能单独支撑一个结论」，不由若干维度加权求和后再比一条分数线。加权求和做不到这件事——在求和口径下「取样方式不明但有认可资质」与「厂商送检」会落在同一条线附近，只要阈值定得低一点两者都能越过，「送检样与市售样不是同一批」这条行业共识就等于没写。

| 来源身份 | 门槛 | 依据 |
|---|---|---|
| 监管机构 | 通过 | 监管公开信息 |
| 平台机构 | 通过 | 平台规则文本 |
| 厂商自述 | 通过；取样为厂商送检时不通过 | 厂商标称可作为「厂商是否这样标称」的依据 |
| 独立第三方 | 取样为厂商送检则不通过；取样不明但有认可资质则通过 | 送检样与市售品不是同一批 |
| 用户自述 | 不通过 | 用户内容不能单独支撑结论 |
| 未知 | 不通过 | 来源身份不可核 |

**取样方式与资质只决定门槛，不再参与计分。** 独立第三方的取样方式（市场随机购买／厂商送检）与认可资质是门槛的判据；厂商自述只在厂商送检时不通过。给监管公开库、平台规则、用户内容标注取样方式与资质属于记录性字段，既不影响门槛也不影响排序。

## 三、权威性排序

门槛回答「够不够格」，**排序**回答「多条来源都够格时听谁的」。两者是不同职责，不能用一个分数兼任：一旦让资质与取样加分，同一个事实就被计算两次，而且低等级身份可能靠加分贴近高等级身份，权威性会依赖数值巧合。

排序用**有序元组**，不经过任何分数。元组越小越权威：

| 位置 | 取值 | 顺序 |
|---|---|---|
| 1 来源身份 | 监管机构 / 独立第三方 / 平台机构 / 厂商自述 / 未知 / 用户自述 | 由左到右 |
| 2 取样方式 | 市场随机购买 / 取样方式未说明 / 厂商送检 | 由左到右 |
| 3 资质 | 有认可资质 / 无 | 由左到右 |
| 4 日期 | 越新越靠前；日期缺失或无法解析排最后 | 由新到旧 |

规则后果：

- **身份优先于其余三项**：低等级身份无论取样多好、资质多全，都不会超过高等级身份；
- 只有第一位置相同（同级来源）时，才比较取样、资质与日期；
- 缺失日期、缺失字段与无法解析的输入都有确定位置，排序稳定可复现；
- 旧数据只有 A–D／E1–E4 等级时，按等级折算成身份位置后仍可与带维度的证据比较。

## 四、展示权重

展示权重是三档值，由门槛结论与身份推出，**只用于报告与界面展示**：

| 情形 | 权重 |
|---|---|
| 通过门槛，且非厂商自述 | 0.90 |
| 通过门槛，且为厂商自述 | 0.70 |
| 未通过门槛 | 0.40 |

除旧数据（只有等级、没有维度信息）按等级折算外，权重不再叠加取样与资质的加减项。报告只写「过门槛／未过门槛」与三档权重，不出现「基准 0.85 + 0.10」这类算式——那会让读者以为资格是算出来的。

## 五、独立来源

「独立来源数」按**发布者**去重，不按资料编号：同一家机构的两次检测、同一篇文章的两个转载版本，都只是一个来源。发布者不明时不计入独立来源——退回资料编号会把同一家机构的两份材料算成两个来源，而独立来源数正是允许对外动作的门槛，宁可少算不可多算。

## 六、门槛之外的后果

门槛通过与否还决定一件事：**承载结论的来源全部是厂商自述时，不得触发对外动作**（降级分发、打标、转违规一律改写为转人工）。依据是举证责任——平台做了对外动作就要拿得出可以摆到申诉与监管面前的独立依据，而厂商自述只能证明「厂商是这么说的」。见「处置档位」的 R13。

## 七、使用规则

- E4 不能单独支撑 SUPPORTED；
- E3 可以支撑 SUPPORTED，但报告需标注证据强度为中等；
- E1 与 E2 冲突时标 SOURCE_CONFLICT 并进入人工复核；
- 同一结论有两条以上独立来源时，报告标注证据强度为高。
