# 主张抽取与标注规则

规则的目标是：两个人独立标注同一段内容，得到基本一致的结果。本文档同时是 Prompt 约束与评测口径的来源。

## 一、核查单元

核查单元是**可独立判定的最小事实性主张**。拆分规则：

1. 一条主张只包含一个可验证的核心判断。出现「而且」「并且」「同时」时，通常需要拆开；
2. 数值与限定条件属于同一条主张。条件被省略不是另一条主张，而是该主张的标志位；
3. 因果表述拆成两部分：事实部分与因果关系。事实可以判定，因果关系在没有对照实验时标为证据不足；
4. 比较型主张需要两边数据齐全才能判定；只给出一边对比数据时标为证据不足。

不核查的内容：纯主观偏好（「我觉得手感不错」）、修辞夸张（「好用到哭」）、无事实指向的口号（「年轻人的第一台」）、作者个人的使用习惯与作息（「我每天通勤两小时」）。

## 二、主张类型

| 类型 | 说明 | 例子 |
|---|---|---|
| 数值型 | 具体数字，可容差比较 | 续航 40 小时 |
| 范围型 | 涉及型号、批次、地域范围 | 全系支持无线充电 |
| 排他型 | 唯一、第一、独家 | 行业第一、独家专利 |
| 认证型 | 资质、检测、认证 | 通过抗菌认证 |
| 健康安全型 | 功效、成分、安全 | 4 周体能改善 |
| 因果型 | 把相关说成因果 | 泵压更高所以更浓 |
| 时间型 | 与特定时间点绑定 | 现在到手价 899 |

## 三、主判定

每条主张只给一个主判定。

| 判定 | 定义 | 触发条件 |
|---|---|---|
| SUPPORTED 支持 | 存在有效证据支持该主张 | 至少一条 E1／E2 证据直接支持，且无相反证据 |
| PARTIAL 部分支持 | 主张本身有真实依据，但遗漏了会改变理解的条件或范围 | 证据成立但条件、范围、浓度、档位等被省略 |
| CONTRADICTED 冲突 | 存在有效证据与主张相反 | 至少一条 E1／E2 证据直接否定主张 |
| INSUFFICIENT 证据不足 | 现有资料无法支持也无法否定 | 只有营销来源、资料互相矛盾、资料过期、范围错配 |

判定优先级：先看是否存在有效证据，再看证据是否直接指向该主张，最后才考虑证据等级。**不允许在证据不足时给 SUPPORTED 或 CONTRADICTED。** 检索不到相关记录不等于反证，只能得到 INSUFFICIENT。

## 四、标志位

标志位可多选，用于说明判定成因，也用于单独统计。

| 标志 | 含义 |
|---|---|
| STALE | 依据的资料已过期或版本不符 |
| SOURCE_CONFLICT | 有效资料之间互相矛盾 |
| SCOPE_MISMATCH | 资料覆盖的范围与主张不一致，例如型号、批次、部位 |
| OMITTED_CONDITION | 主张省略了影响结论的条件 |
| UNIT_MISMATCH | 单位或统计口径不一致 |
| LOW_SOURCE_QUALITY | 仅存在营销或不可溯源来源 |

## 五、时效规则

资料是否过期按品类判断，超过下表时限的视为 STALE。

| 品类 | 有效期 |
|---|---|
| 数码与家电规格 | 12 个月 |
| 食品与保健品 | 6 个月 |
| 护肤与美妆成分配方 | 18 个月 |
| 价格与促销 | 7 天 |
| 认证与资质 | 以证书标注的有效期为准，过期即 STALE |

资料过期只影响它作为证据的有效性。除非有现版本资料明确否定该主张，否则过期资料导致的结果是 INSUFFICIENT 加 STALE，而不是 CONTRADICTED。

## 六、数值与范围规则

1. 数值容差按「容差」文档的表格执行，单位换算后比较，超出容差才判为冲突；
2. 范围型主张按最窄范围判定，例如「全系支持」只要有任一型号不支持，即为 CONTRADICTED 加 SCOPE_MISMATCH；
3. 限定条件规则：主张省略了在资料中出现且会改变结论的条件时，判为 PARTIAL 加 OMITTED_CONDITION。判断关键是该条件会不会影响用户的理解，而不是条件是否存在于资料中；
4. 条件已经写在内容里的不算省略。内容写「关闭降噪时续航 40 小时」、资料写「关闭降噪 40 小时、开启降噪 28 小时」，该主张判 SUPPORTED；只有内容写「续航 40 小时」而没写条件时，才判 PARTIAL。

## 七、人工复核队列

进入复核队列的条件：

- 判定为 CONTRADICTED；
- 判定为 PARTIAL；
- 带有 SOURCE_CONFLICT 或 STALE 标志；
- 判定为 INSUFFICIENT，且属于数值、认证、健康安全或排他型主张。

不进队列的 INSUFFICIENT 只在报告中标明「证据不足」，不阻塞流程。

## 八、标注流程与一致性

任务集由两人独立标注，分歧项进入仲裁。一致性用 Cohen's kappa 衡量，主判定 kappa 低于 0.7 时说明规则仍有歧义，先改规则再评测。

标注顺序：先拆主张，再逐条判主判定，最后补标志位。不允许先看判定再倒推主张。

## 九、错误分级

| 等级 | 定义 | 例子 |
|---|---|---|
| P0 | 影响内容处置方向 | 证据不足被判为支持；冲突被判为支持 |
| P1 | 影响复核效率 | 主判定方向正确但标志位缺失；应进队列但未进 |
| P2 | 影响报告体验 | 引用定位不精确；说明文字冗长 |

评测报告的结论以 P0 数量为首要指标，P1 次之。

## 十、常见标注错误

1. 把限定条件当成独立主张，一条主张被拆成两条；
2. 资料过期就判为 CONTRADICTED，混淆了「证据失效」与「证据反对」；
3. 资料互相矛盾时直接取更权威的一方，忽略了应标记冲突待复核；
4. 把营销来源当作有效证据，忽略 E4 不能单独支撑结论；
5. 用户实测与官方参数冲突时直接采信官方，忽略了可能是版本或批次差异。
