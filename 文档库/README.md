# 文档库（标准文档）

本目录存放**标准文档**：已定稿、可直接引用的规则、口径与依据。

## 与 docs/ 的分工

| 目录 | 定位 | 收录内容 |
|---|---|---|
| `docs/` | 工作区 | 讨论过程、修改记录、实验数据、未决事项 |
| `文档库/` | 标准库 | 已定稿的规则、口径、架构与外部依据 |

四条纪律：

1. 日常修改在 `docs/` 内进行，定稿后同步到本目录；
2. 同步时机为大版本变更（规则口径发生变化）或定期整理，不做逐次同步；
3. 本目录不出现过程性表述：不含讨论记录、修改缘由、未决事项与提议性措辞；
4. 每条规则必须能追溯到依据；依据尚未逐条落实的，在本目录内标「依据状态：待补」，不得写成已核实。
